# yottaflex-supply-chain-traceability
YottaFlex is an end-to-end supply chain traceability and recall management system that enables real-time product genealogy, raw material tracking, production monitoring, shipment traceability, automated anomaly detection, and recall management.

AI tools were used as development assistance during this project.

*Tools used:*
- ChatGPT – planning, technical explanations, debugging guidance, code review suggestions and validation assistance.
- Antigravity IDE – AI-assisted development and implementation support.

*How AI was used:*
- Understanding technical requirements and architecture.
- Troubleshooting implementation issues.
- Reviewing data generation and edge-case logic.
- Supporting testing and validation workflows.
- Improving project documentation.
